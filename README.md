# Road Facility Management System

This project provides a simple map-based web application for managing road facilities.

## Requirements

- Python 3.11+
- Flask (see `requirements.txt`)

Install dependencies with:

```bash
pip install -r requirements.txt
```

## Running

```bash
python app.py
```

Then open `http://localhost:5000/` in your browser.

Facilities added through the form are stored in `data/road_facilities.json`.
